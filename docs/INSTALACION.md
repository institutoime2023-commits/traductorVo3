# Guía de Instalación y Despliegue en GitHub

1. Descomprimir el repositorio `TRADUCTOR-ANDROID-V0.3.zip`.
2. Abrir la carpeta en Android Studio (Koala o superior).
3. Sincronizar Gradle (`Sync Project with Gradle Files`).
4. Conectar el Xiaomi Redmi 12C mediante USB con la depuración USB activada.
5. Ejecutar la aplicación (Run 'app') para compilar e instalar en el dispositivo físico.
